# Masonic Atlas — Freemasonry Encyclopedia

Independent educational PWA built from public information and source-linked archival media.

## Features
- 35 encyclopedia articles
- Craft overview and all 29 Scottish Rite NMJ degrees (4°–32°)
- 30-symbol encyclopedia
- 45-term glossary
- 15 people profiles with claim-status labels
- 22-event timeline
- real archival/public-domain/Creative-Commons media with credit links
- search, bookmarks, theme controls, quiz, offline-capable app shell
- installable PWA
- public ritual overview only; no current passwords, signs, grips or private test material

Hosted separately from the rest of this repository through Render using this folder as the publish path.

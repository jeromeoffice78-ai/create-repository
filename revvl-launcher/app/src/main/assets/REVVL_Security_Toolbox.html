REVVL Super Tablet • Local security workspace

Security Toolbox

Tap a tool to perform a real, read-only diagnostic and see its results. Website checks use the REVVL Android service; file and password checks stay in Chrome on this tablet. This is an authorized security assessment toolkit, not an automatic break-in system.

Authorized target

Only public HTTPS domain names are accepted. The toolkit blocks IP addresses, private networks, port ranges, and unapproved scanning.

DNS Inspector

Resolve the website's public IPv4 and IPv6 records.

Instructions

Enter your approved domain above, check authorization, and tap Run. Read A (IPv4) and AAAA (IPv6) addresses in the results. DNS records are not vulnerability findings.

TLS Certificate Audit

Inspect HTTPS certificate issuer, validity dates, and fingerprint.

Instructions

Enter a public authorized hostname. Tap Run to establish a verified TLS connection. Review certificate expiry and issuer; report unexpected or expiring certificates to the site's administrator.

HTTP Security Headers

Send one HTTPS HEAD request and list security header settings.

Instructions

Enter the website hostname. Tap Run to inspect HSTS, CSP, X-Content-Type-Options, Referrer-Policy, Permissions-Policy and X-Frame-Options. Missing headers are review points and may have legitimate configuration reasons. This tool does not exploit websites.

REVVL Local Services

Check your local dashboard, 3D Engine, and optional AI bridge.

Instructions

Tap Run. This checks only ports 8788, 8770 and 8767 on this tablet. A successful connection means a listener exists; it does not validate all features.

File SHA-256 Fingerprint

Verify the digital fingerprint of a file from Downloads, without uploading it.

Instructions

Tap Select File, choose a file from the tablet, and view its SHA-256 digest. Compare it with a publisher's official checksum to detect accidental or malicious file changes. Maximum file size: 32 MB.

Local Password Strength

Estimate password quality without sending or saving text.

Instructions

Use a sample passphrase, not an important account password. Tap Evaluate and review length and character diversity. A length estimate cannot tell whether a password is breached; a password manager and MFA are recommended.

Additional professional tools
For advanced, authorized work, use the official tools on a supported computer or Linux installation: Nmap, Wireshark, OWASP ZAP, and the OWASP Web Security Testing Guide. These links are educational resources; they do not install or launch those programs on the tablet.


Limitations: This dashboard does not do password cracking, unauthorized intrusion, exploit execution, credential collection, or Internet-wide scanning. The native tools are read-only and require a public domain or use only fixed REVVL localhost service ports.

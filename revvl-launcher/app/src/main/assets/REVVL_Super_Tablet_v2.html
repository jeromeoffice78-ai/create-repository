Free-first character modeling · Workstation workflow

Blender + MPFB — Free, open-source character creation

Use the approved portraits as references for a customized 3D human in Blender with the free MPFB (MakeHuman Plugin for Blender) add-on. MPFB creates meshes, materials and rigs; it does NOT automatically produce an exact lookalike from one picture. Refine facial geometry and materials manually, then test the rig and expressions.

Get Blender — free Get MPFB — free MPFB documentation Remote workstation

Prepare an approved cast member

Your saved approved portrait downloads locally without alteration. These buttons do not transmit photos to external websites or claim a 3D likeness was generated.

Free production pipeline

1. Import the approved portrait as a Blender reference. 2. Build the human base mesh in MPFB. 3. Match facial dimensions using additional front/side references. 4. Set skin, eyes, hair and approved wardrobe. 5. Use MPFB/Rigify for the skeleton. 6. Add facial morphs and speech controls. 7. Export a rigged GLB and inspect likeness, skin weights, animation and lip-sync before release.

Requires a compatible computer or cloud workstation running Blender. Android REVVL serves as the control and file-transfer screen. No automatic photo-accurate reconstruction is implied.

Daz Studio — Optional, paid-feature route

Daz Studio's base application is free, but the full workflow needed for eight realistic characters may cost money. Face Transfer 2 is separately sold (listed at US $49.95 when checked), the trial limits saved unwatermarked figures, and some Genesis assets are paid. Daz is NOT required for the free Blender/MPFB workflow.

Remote CPU · Remote GPU · Workstation status

Supercomputer Control Center

Use your REVVL tablet as a secure control screen for an independently configured high-performance workstation. The tablet's hardware stays the same; remote CPUs, GPUs and Blender are accessed through an authenticated HTTPS gateway.

No cloud machine is provisioned by this app. A separately operated compute gateway, valid access token and network connection are required. Paid cloud providers may charge for running hardware.
